# Build apps for Vector Spaces

A Vector app is a TypeScript package with a React client and a Node server that runs inside a [Space](/glossary#space). One app definition lists the pages and [capabilities](/glossary#capability) of your app. The Space shows a page only to users who hold the page's capability.

<Link className="button button--primary button--lg" to="/quickstart">Start Quickstart</Link>

```ts title="shared/src/index.ts"
import { defineApp } from '@vectoragents/vs-apps';

export const definition = defineApp({
  key: 'hello-app',
  version: '0.1.0',
  pages: [{ key: 'home', label: 'Home', path: '/', capability: 'hello:view' }],
  capabilities: [{ key: 'hello:view', label: 'View hello', effect: 'read' }],
});
```
